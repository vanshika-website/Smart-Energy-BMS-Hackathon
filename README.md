# Smart Energy BMS Dashboard

IoT-powered energy management dashboard for monitoring and optimizing household appliance power consumption.

## Features
- **Phase Monitoring**: Real-time load tracking for Phase 2 and Phase 3.
- **Emergency Notifications**: Automatic alerts for AC/Heater overload with shutdown controls.
- **Data Visualization**: Live power consumption vs savings charts.
- **Realistic Telemetry**: High-fidelity sensor simulation with jitter and nominal load baselines.

## Tech Stack
- **Frontend**: React, TypeScript, Vite, Recharts, TailwindCSS.
- **Backend**: Node.js, Express, Firebase Realtime Database.

## Getting Started
1. **Backend**: `cd BACKEND && npm install && npm start`
2. **Frontend**: `cd "FRONTEND DASHBOARD" && npm install && npm run dev`
